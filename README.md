# Farmacia san pablo
Proyecto escolar para el control de medicamento, laboratorio, clientes y ventas en una farmacia
## funciones
-inicio de sesion
-registro y consulta de medicamentos
-consultas de procedimientos almacenados
## tecnologias
-PHP
-MySQL/MariaDB
-HTML  y CSS
## como ejecutarlo
1. Instalar XAMMP (o apache + php + mariadb)
2. copia la carpeta del proyecto en 'htdocs'
3.importa 'farmaciasanpablo.sql' desde phpMyAdmin
4.abre 'htt://localhost/farmaciasanpablo'
##pendientes
-usar consultas preparadas contra SQL injection
-migrar las tablas a InnoDB con llaves foraneas 
-guardar usuarios con constraseñas cifradas
